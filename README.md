# A TIGER GLOBAL — Career Solution & Consultancy

A modern, production-grade responsive frontend web application for **A TIGER GLOBAL Career Solution & Consultancy** (Proprietorship), built with React 19, TypeScript, Vite, Framer Motion, and a custom Vanilla CSS design system.

---

## 🌟 Brand & Color System

- **60% Pearl White** (`#FCFBFB`) — Base layout, cards, and clean typography backdrop.
- **25% Midnight Navy** (`#192A56`) — High-contrast hero, sticky navigation, and headers.
- **10% Champagne** (`#F7D794`) — Accent highlights, badges, and primary action buttons.
- **5% Dusty Rose** (`#EDA6A3`) — Secondary alert tags and subtle highlights.

---

## 🚀 Key Features & Pages

- **Homepage (`/`)**: Cinematic hero, animated statistics counters (800+ Placed, 400+ Active Employees, 3 States, 3+ Partners), trusted employer logos, services overview, two-audience split conversion, central India regional map, and 4-step candidate journey.
- **About Us (`/about`)**: Company background, mission, vision, operational scale, dual commitments, and employer partnerships.
- **Services (`/services`)**: In-depth breakdowns of Job Placement Consultancy, Labour & Manpower Supply, and Security Guard Supply.
- **Jobs Board (`/jobs`)**: Recruitment board with keyword search, state filter (Maharashtra, MP, CG), category filter, and job type filter.
- **Job Details (`/jobs/:slug`)**: Detailed job descriptions, responsibilities, requirements, and direct apply triggers.
- **Candidate Enquiry Wizard (`/enquiry`)**: 5-step interactive wizard (Personal, Preferences, Education, Contact, Review) with validation and success state.
- **For Employers (`/employers`)**: Enterprise staffing solutions and direct commercial Rate Quote inquiry form.
- **Contact Us (`/contact`)**: Official Nagpur headquarters address, phone helpline, email, WhatsApp direct chat, office hours (11:00 AM – 4:00 PM), and interactive map placeholder.
- **Joining Gateway (`/joining`)**: Onboarding procedure overview and Registration Form-5 document checklist.
- **Policy & Terms (`/policy`)**: Exact client-provided 10-point terms and conditions with printable layout.
